
☁️ AWS Cloud Journey — Study Materials & Hands-On Projects 🚀

Welcome to my AWS Learning Repository!
This repo is a personal collection of my college-level AWS projects, notes, and experiments, built to explore how the cloud powers real-world applications. 🌍
Here, you’ll find everything — from launching EC2 instances to hosting websites on S3 and managing secure email with AWS WorkMail.

🔥 What’s Inside
🖥️ EC2 (Elastic Compute Cloud)

💡 “The heart of cloud computing.”

Launched & managed multiple EC2 instances.

Configured security groups, key pairs, and scaling policies.

Deployed demo apps and connected EC2 with other AWS services.

🌐 S3 (Simple Storage Service)

🪣 “Storage meets simplicity.”

Hosted a static website using S3 Buckets.

Configured bucket policies, versioning, and public access control.

Managed data uploads and automatic file backups.

📩 AWS WorkMail

📬 “Professional communication in the cloud.”

Set up custom WorkMail domains for team collaboration.

Integrated with IAM for secure role-based access.

Managed mail routing and organizational communication.

⚙️ AWS Networking & Instances

🌐 “Building secure, connected environments.”

Created Elastic IPs and configured VPCs, Subnets, and Route Tables.

Experimented with load balancing and auto-scaling groups.

Enhanced app security using IAM roles & policies.

🔗 S3 + EC2 Integration

🔄 “Where storage meets compute.”

Connected EC2 instances to S3 for data transfer.

Automated file handling using Python scripts & IAM roles.

Streamlined deployments between compute and storage layers.

🧠 What I Learned

🚀 How to build, deploy, and manage scalable cloud infrastructure.

🔐 The importance of security, reliability, and network configuration.

🧩 How AWS services integrate for seamless DevOps workflows.

💻 Real-world exposure to cloud architecture and automation.
